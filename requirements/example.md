# 要件の例: テーブル内集計（アプリ 2305）

アプリ番号 2305「テーブル内集計」。テーブル「テーブル」に明細と小計の行が混ざって並ぶ。分類（ドロップダウン: 概要 / 明細 / 小計）で行の種類を分ける。

1. テーブルの「No」に行番号（1 から）を自動で入れる
2. 「明細」の行の「金額」は 数量 × 単価
3. 「小計」の行の「金額」は、その行より上にある、直前の小計（または先頭）より後の「明細」の金額の合計
4. 「数量」「単価」は「明細」の行だけ入力値のまま。それ以外の行（概要・小計）では空にする
5. 「小計」の行の「商品」は、その区切り（直前の小計より後）にある「概要」の行の「商品」を入れる。ほかの行の「商品」は入力値のまま
6. テーブルの外の「金額合計」は、「小計」の行の金額の合計

計算式を書く前に、あいまいな点（空のときの値、同じ分類が無いときなど）を確かめること。既存のレコードは変わらないこと（反映方法を最後に伝えること）。
